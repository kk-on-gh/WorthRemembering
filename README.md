# Worth Remembering

A personal notes and reputation tracker for WoW: Forever. Keep timestamped notes and a -100..+100 standing on the players you meet, so you can actually remember who helped you out, who to avoid, and what you were doing when you crossed paths.

Full feature rundown and screenshots: https://www.curseforge.com/wow/addons/worth-remembering

See [CHANGELOG.md](CHANGELOG.md) for release notes.

## Installation

Drop the `WorthRemembering` folder into your `Interface/AddOns` directory, or install via CurseForge/a CurseForge-compatible addon manager.
